Comment je travaille

Un déroulé simple, pour que vous sachiez toujours où en est votre projet.

    Brief

    Vous recevez un devis clair avec les livrables, le délai et le prix. Le projet démarre après l’acompte de 50 %.

    Vous recevez vos fichiers organisés, prêts pour le web et l’impression, avec les règles d’usage de votre marque.
